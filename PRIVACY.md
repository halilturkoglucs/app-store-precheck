# Privacy

App Store & Google Play Precheck has no server of its own and contains only instructions for Claude. The author does not receive, collect or store your code, store console data or usage data.

The skill asks Claude to read your project's source files, build settings and store listing text. Claude Code handles that content under the terms of your Claude plan.

What else leaves your machine:

| Action | Sent to | Data |
|---|---|---|
| Re-checking a rule against the official page | `developer.apple.com`, `play.google`, `support.google.com` | Ordinary page requests, with no code or app data |

The skill never asks for store passwords, API keys or payment details. If you share console screenshots, they go to Claude like any other message.

The plugin stores nothing.

Questions: open an issue at https://github.com/halilturkoglucs/app-store-precheck/issues
